# NeuralPath

A responsive, device-local learning tracker for Vishwa's AI Engineering and Applied Deep Learning roadmaps.

## Included

- Complete AI Engineering course roadmap and minimum prerequisites
- Applied Deep Learning roadmap
- JSON roadmap uploads with support for multiple additional roadmaps
- Roadmap priority ordering and safe removal through custom settings
- Expandable subtopic checklists, automatic parent counts and per-topic notes
- Custom start dates and deadlines on main roadmap topics with a live deadline-horizon indicator
- Search and completion/note filters
- Progress analytics, activity streak and focus-time tracking
- 25, 45 and 60 minute focus sessions
- Dark and light themes
- JSON backup, restore and full reset
- Responsive desktop, tablet and mobile layouts

## Run locally

Open `index.html` directly, or serve this directory with any static web server for the best experience.

Progress is stored in the browser's local storage. Use **Backup & restore** inside the site to move or preserve it.
